# Computer Graphics — Pages Demo

스테레오 표면 렌더러의 정적 웹 시연입니다.

기존 KITTI 시연에서 복원한 39,983개 점과 표면 속성을 포함합니다. 브라우저에서는 저장된 결과를 표시하며 Python 스테레오 복원은 실행하지 않습니다.

원본 프로젝트: https://github.com/gshark1348/computer-graphics-termproject (비공개)

Three.js 0.180.0의 MIT 라이선스는 vendor/three/LICENSE에 포함되어 있습니다.
KITTI 데이터 출처 및 이용 조건: https://www.cvlibs.net/datasets/kitti/

GitHub Pages: main 브랜치의 루트(/)에서 배포합니다.
